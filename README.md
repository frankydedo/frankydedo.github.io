# frankydedo.github.io

Personal portfolio of Francesco Pio De Dominicis — live at **https://frankydedo.github.io**.

Plain HTML + CSS, no build step. Theme follows the OS (light / dark).

- `index.html` — English (default)
- `it/index.html` — Italian
- `assets/css/style.css` — design tokens, Liquid Glass components, responsive rules
- `assets/Francesco-Pio-De-Dominicis-CV.pdf` — downloadable CV

Run locally:

```bash
python3 -m http.server 4321
```
